System Architecture

Three-Tier Architecture

┌─────────────────────────────────────────┐ │ PRESENTATION LAYER │ │ • Web Browser (HTML/CSS/JS) │ │ • Chat Interface │ │ • Results Display │ └─────────────────────────────────────────┘ ↕ HTTP/JSON ┌─────────────────────────────────────────┐ │ BUSINESS LOGIC LAYER │ │ • ChatbotController (API Endpoint) │ │ • ChatbotService (Business Logic) │ │ • InvoiceQueryParser (NLP Engine) │ └─────────────────────────────────────────┘ ↕ SQL ┌─────────────────────────────────────────┐ │ DATA ACCESS LAYER │ │ • OnbaseRepository (Dapper ORM) │ │ • SQL Server (Onbase Database) │ └─────────────────────────────────────────┘

Key Components

  • ChatbotController: Receives HTTP requests, returns JSON responses
  • ChatbotService: Orchestrates query processing and response generation
  • InvoiceQueryParser: Custom NLP engine using regex patterns
  • OnbaseRepository: Executes optimized SQL queries with Dapper

Natural Language Processing (NLP) Engine

Custom Regex-Based Approach

Unlike heavy AI models (GPT, BERT), we built a lightweight, deterministic NLP engine using regular expressions.

Advantages

Feature Benefit
✓ Fast Sub-millisecond parsing time
✓ Predictable No AI hallucinations or errors
✓ No API Costs Runs locally, $0/month
✓ Privacy No data sent to external services
✓ Customizable Easy to add new patterns

How It Works

  1. User enters natural language query
  2. NLP engine analyzes keywords and patterns
  3. Identifies intent (date search, amount search, etc.)
  4. Extracts parameters (dates, amounts, invoice numbers)
  5. Routes to appropriate database query

Parameter Extraction

Date Extraction

Supports multiple date formats:

  • ISO 8601: 2025-03-01
  • US Format: 03/01/2025
  • European: 01/03/2025
  • Relative: "this month", "last year", "yesterday"
// ISO Format Pattern var isoDatePattern = @"(\d{4})[/-](\d{1,2})[/-](\d{1,2})"; // Common Format Pattern var datePattern = @"(\d{1,2})[/-](\d{1,2})[/-](\d{2,4})"; // Relative Date Handling if (prompt.Contains("this month")) { var startOfMonth = new DateTime(today.Year, today.Month, 1); return (startOfMonth, today.AddDays(1)); }

Amount Extraction

// Extract numeric amounts var amountPattern = @"(\d+(?:\.\d{2})?)"; // "between 1000 and 10000" → min=1000, max=10000

Query Processing Flow

Example: "Find invoices between 2025-03-01 and 2025-03-30"

Step 1: Frontend (JavaScript) → User types query and clicks "Send" → POST /api/chatbot/query Step 2: Controller (ChatbotController.cs) → Receives HTTP request → Calls ChatbotService.ProcessQueryAsync() Step 3: NLP Parser (InvoiceQueryParser.cs) → Detects Intent: "SearchByDate" → Extracts: startDate=2025-03-01, endDate=2025-03-30 Step 4: Service (ChatbotService.cs) → Routes to GetInvoicesByDateRangeAsync() Step 5: Repository (OnbaseRepository.cs) → Builds SQL query with parameters → Executes with Dapper → Returns List<Invoice> Step 6: Service (Generate Response) → Creates message: "I found 249 invoice(s)..." → Builds ChatResponse object Step 7: Controller (Return JSON) → Serializes to JSON → Returns HTTP 200 Step 8: Frontend (Display Results) → Renders invoice cards

Onbase Database Schema

Table Structure

Table Key Field Contains
hsi.itemdata itemnum (PK) Master invoice table
hsi.keyitem106 keyvaluesmall Invoice numbers
hsi.keyitem112 keyvaluedate Invoice dates
hsi.keytable104 keyvaluechar Order/PO numbers

Sample SQL Query

SELECT i.itemnum as InvoiceId, CAST(ki106.keyvaluesmall AS VARCHAR(50)) as InvoiceNumber, ki112.keyvaluedate as InvoiceDate, kt104.keyvaluechar as PONumber FROM hsi.itemdata i WITH (NOLOCK) LEFT JOIN hsi.keyitem106 ki106 WITH (NOLOCK) ON i.itemnum = ki106.itemnum LEFT JOIN hsi.keyitem112 ki112 WITH (NOLOCK) ON i.itemnum = ki112.itemnum WHERE i.itemtypenum = 102 AND ki112.keyvaluedate BETWEEN @StartDate AND @EndDate ORDER BY ki112.keyvaluedate DESC

Pagination Support

Problem Solved

When searching returns hundreds of invoices, users need to navigate through results page by page.

Supported Syntax

Pattern Example Result
skip X "skip 5" Skip first 5 results
take X "take 10" Take 10 results
skip + take "skip 5 take 10" Show results 6-15
first X "first 20" Show first 20 results

Example Queries

Query: "Find invoices in March 2025 take 10" Result: Shows first 10 invoices Query: "Find invoices in March 2025 skip 10 take 10" Result: Shows invoices 11-20 Query: "Find invoices in March 2025 skip 100 take 20" Result: Shows invoices 101-120

Security Features

SQL Injection Prevention

All queries use parameterized queries via Dapper:

// ✓ SAFE - Parameterized query var query = @"SELECT * FROM hsi.itemdata WHERE date BETWEEN @StartDate AND @EndDate"; await connection.QueryAsync<Invoice>(query, new { StartDate = start, EndDate = end }); // ✗ UNSAFE - String concatenation (NOT USED) var query = $"SELECT * WHERE date = '{userInput}'";

Authentication

  • Current: Windows Integrated Security
  • Future: API key authentication for external access

Input Validation

  • Query length limits (1-500 characters)
  • Pagination parameter validation
  • Date range validation
