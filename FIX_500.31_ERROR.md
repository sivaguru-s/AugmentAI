# Fix HTTP Error 500.31 - ASP.NET Core Runtime Not Found

## Error Description
```
HTTP Error 500.31 - Failed to load ASP.NET Core runtime
The specified version of Microsoft.NetCore.App or Microsoft.AspNetCore.App was not found.
```

## Root Cause
The server **AAZEUS-FNUKAP01** does not have:
1. **.NET 8.0 Runtime** installed, OR
2. **ASP.NET Core Hosting Bundle** installed

## Solution Options

### **Option 1: Install .NET 8.0 Hosting Bundle (RECOMMENDED)**

This is the easiest solution for IIS deployments.

#### Step 1: Download the Hosting Bundle

On the server **AAZEUS-FNUKAP01**, download:

**Direct Download Link:**
```
https://dotnet.microsoft.com/download/dotnet/8.0
```

Look for: **"ASP.NET Core Runtime 8.0.x - Windows Hosting Bundle"**

Or use this direct link (latest stable):
```
https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/runtime-aspnetcore-8.0.2-windows-hosting-bundle-installer
```

#### Step 2: Install the Hosting Bundle

1. Run the downloaded installer: `dotnet-hosting-8.0.x-win.exe`
2. Follow the installation wizard
3. **Restart IIS** after installation:
   ```powershell
   net stop was /y
   net start w3svc
   ```

#### Step 3: Verify Installation

```powershell
# Check installed .NET runtimes
dotnet --list-runtimes

# Should show:
# Microsoft.AspNetCore.App 8.0.x [C:\Program Files\dotnet\shared\Microsoft.AspNetCore.App]
# Microsoft.NETCore.App 8.0.x [C:\Program Files\dotnet\shared\Microsoft.NETCore.App]
```

#### Step 4: Test the Application

Navigate to:
```
http://localhost/chatbotonbase/
```

---

### **Option 2: Self-Contained Deployment**

If you cannot install .NET on the server, publish as self-contained.

#### Step 1: Modify the Build Command

On your development machine:

```powershell
cd C:\Chatbot-Onbase

# Publish as self-contained for Windows x64
dotnet publish -c Release -r win-x64 --self-contained true -o ./publish-selfcontained
```

#### Step 2: Deploy to Server

Copy the `./publish-selfcontained` folder to:
```
\\aazeus-fnukap01\c$\inetpub\wwwroot\chatbotonbase\
```

**Note:** Self-contained deployments are larger (~100MB vs ~10MB) but include the runtime.

```powershell

dotnet --version
```

## Troubleshooting

### Issue: "dotnet command not found"

**Solution:**
- .NET is not installed
- Install the Hosting Bundle (Option 1)

### Issue: Still getting 500.31 after installing

**Solution:**
```powershell
# Restart IIS completely
iisreset /restart

# Or restart the app pool
Restart-WebAppPool -Name "ChatbotOnbaseAppPool"
```

### Issue: Wrong .NET version installed

**Check version in project:**
```xml
<!-- Chatbot-Onbase.csproj -->
<TargetFramework>net8.0</TargetFramework>
```

**Install matching version:**
- Project uses .NET 8.0
- Install .NET 8.0 Hosting Bundle
